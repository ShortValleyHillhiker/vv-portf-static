Styleguide

This page exists to design against. It uses every block once, so the whole vocabulary can be judged together instead of piecemeal across cases.

Lead text. The larger opening paragraph, set in the display family. Use it once per case, right after the preamble or the first image.

Body text. Capped at a 62-character measure regardless of viewport width. This is the block that does most of the work in a case, and the measure cap is the single reason it reads better than the previous build. Inline links get the highlighter wipe on hover.

Image — full width, 16/9

Grid — two columns, mixed ratios, span="2" goes full width

Raw markdown still works between blocks

A heading written in plain markdown

Paragraphs written as ordinary markdown, with no shortcode around them, pick up the same measure and rhythm as a text block. That is the point — you only reach for a shortcode when markdown genuinely cannot express the layout.

  • List items are styled too
  • So you never have to wrap prose in anything
  • Which is most of the “template overhead” gone
